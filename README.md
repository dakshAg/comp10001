## How to do well in this subject?
Practice. Programming is like working out. The best way to get better is to do it your yourself, watching others work-out and talk about work-out won't build your muscles, you have to do the lifting yourself!
Do your Grok Worksheets, all Tutorial Questions and Past Exams, and you're good to go. Need more practice on some topics? Ask ChatGPT or your tutor to generate more questions.

Practice writing code on paper, since the MST and the Exam are probably conducted on-paper. It isn't as bad as it sounds since you'll be only writing very short snippets, and certainly easier than writing code on a Canvas quiz.
